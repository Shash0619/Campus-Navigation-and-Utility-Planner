# Campus Navigation and Utility Planner  
Simple Python implementation of Trees and Graph Algorithms for university campus navigation, building management, and utility planning.

## Features
- Binary Search Tree for storing building information  
- AVL Tree with automatic balancing  
- Graph representation using adjacency list and adjacency matrix  
- BFS and DFS graph traversals  
- Dijkstra algorithm for shortest path  
- Kruskal algorithm for minimum spanning tree  
- Expression Tree for evaluating basic arithmetic expressions  

## Technologies Used
- Python  
- Basic data structures and algorithms  

## File Description
- Main Python file contains implementation of:
  - Building data structure
  - BST and AVL Tree
  - Graph (matrix and list)
  - BFS and DFS
  - Dijkstra shortest path
  - Kruskal MST
  - Expression Tree evaluation
